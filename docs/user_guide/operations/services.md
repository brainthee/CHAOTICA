# Services

**Operations → Services** lists the services the team delivers (e.g. *Network
Device Review*). Each service's page covers the skills and qualifications it
needs, who can deliver it, and its usage.

## Jobs tab

The **Jobs** tab summarises the phases that use the service, then lists them.
Everything on the tab covers only phases on jobs **you can see**, so the counts
always match the lists.

**Summary cards:** total phases, Active, Upcoming, Completed, and total allocated
hours, plus the **Top Clients** and **Top Units** by number of phases.

**Phase lists**, one per pill:

| Pill | Phase statuses |
| --- | --- |
| **Active** | In Progress through Author Pres Updates (testing, Tech QA and Pres QA) |
| **Upcoming** | Pending Scheduling through Ready to Begin (scheduled or planned, not started) |
| **Completed** | Completed, Delivered, Archived |
| **All** | Every phase, including Draft, Cancelled, Postponed and Deleted |

The three groups don't overlap, and cancelled, postponed and deleted phases only
appear under **All**. Each list loads the first time you open its pill. The
figures are cached for up to 10 minutes but refresh as soon as a phase changes.
